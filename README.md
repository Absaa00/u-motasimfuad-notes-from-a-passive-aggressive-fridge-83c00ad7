One funny passive-aggressive note that a smart fridge leaves for its owner:
a single line, dry, petty and specific — the sort of thing a smug appliance
would put on its door screen.

Built for the [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) competition on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

The program writes one line to `/output/entry.txt` (1–200 characters,
deterministic, no network access).

## The note

> The milk expired Tuesday. I kept it at 4°C anyway, out of professionalism.
> You left the door open nine minutes yesterday. We are not the same.
